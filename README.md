# Лабораторно-практичне заняття №1
## Програмні моделі систем координат
Мета роботи
-	Спроєктувати та реалізувати імутабельні програмні моделі для представлення точок у 2D та 3D системах координат.
-	Реалізувати механізми перетворення між декартовою, полярною та сферичною системами координат з використанням статичних фабричних методів.
-	Навчитись обчислювати відстані між точками, використовуючи різні математичні підходи.
-	Провести аналіз продуктивності обчислень для різних представлень даних.

У рамках роботи реалізовано класи:
1. CartesianPoint2D - представлення точки у декартовій системі координат (2D).
2. CartesianPoint3D - представлення точки у декартовій системі координат (3D).
3. PolarPoint - представлення точки у полярній системі координат (2D).
4. SphericalPoint - представлення точки у сферичній системі координат (3D).
5. DistanceCalculator - клас для обчислення відстаней між точками різними методами.
6. Benchmark - клас для вимірювання продуктивності різних підходів.
7. Main - точка входу в програму.

## Інструкції для запуску проекту
### Вимоги:
- Java JDK 8 або новіша версія
- IntelliJ IDEA або інше середовище розробки
### Кроки запуску:
1. Клонувати репозиторій
2. Відкрити проєкт в IntelliJ IDEA.
3. Переконатися, що встановлена правильна версія JDK.
4. Запустити файл Main.java.

### Аналіз та висновки

Обчислення у декартовій системі координат виконуються швидше, оскільки не потребують використання тригонометричних функцій. Полярна система використовує синус та косинус, що збільшує час виконання.

Найшвидшим є підхід з найпростішими формулами (декартовий). Найповільнішим є сферичний, через складні тригонометричні обчислення.

## Загальний висновок

У ході виконання лабораторної роботи закріплено навички роботи з різними системами координат, реалізації математичних обчислень та аналізу продуктивності алгоритмів.
Встановлено, що використання тригонометричних функцій значно впливає на швидкодію програми. Найефективнішими є методи з мінімальною кількістю обчислень.
